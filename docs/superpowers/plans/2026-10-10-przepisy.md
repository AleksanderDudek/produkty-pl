# Przepisy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A "Przepisy" tab of quick high-protein recipes whose macros come from real products, available per store, plus ready protein products — all obeying protein > carbs and protein > fat.

**Architecture:** Store inference from private labels goes into the data pipeline. A pure recipe engine in `src/recipes/` (ingredient definitions, catalog, candidate ranking, per-store resolution, macros and the rule) is unit-tested on fixtures and checked on real data by a script. The UI adds a tab and a page that only renders what the engine returns.

**Tech Stack:** as the app (React 19, TS, Tailwind 4, Vitest). Spec: `docs/superpowers/specs/2026-10-10-przepisy-design.md`.

## File structure

```
scripts/lib/stores.ts          + PRIVATE_LABELS, storesFromBrands()
scripts/lib/transform.ts       stores = observed ∪ inferred
scripts/check-recipes.ts       real-data coverage report (pnpm recipes:check)
src/recipes/
  types.ts                     Macros, IngredientDef, Recipe, Resolved*
  macros.ts                    scale, sum, isProteinForward (the rule)
  ingredients.ts               INGREDIENTS: role, matcher, bounds, typical macros
  catalog.ts                   RECIPES
  candidates.ts                ranked candidates per ingredient (built once)
  resolve.ts                   resolveRecipe / availableStores / bestStore
  ready.ts                     ready products grouped, rule per 100 g
src/hooks/useUrlState.ts       generic replace/push URL state (useViewState wraps it)
src/hooks/useRoute.ts          pathname routing + navigate()
src/components/recipes/        RecipesPage, RecipeCard, IngredientLine, MacroBar, ReadyProducts, StoreChips
src/components/Tabs.tsx        Produkty | Przepisy
```
